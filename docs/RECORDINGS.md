# Записи лекций

Выгрузка ladyzenko.ru от 14 ноября 2026 содержит восемь товаров основного каталога (500–1100 ₽), описания 13 лекций «Школы отцов» и ссылки на 12 полных записей курса: №2–13. Метаданные RuTube подтвердили названия и длительность 54–95 минут. Первая лекция «Привязанность в отношениях» осталась без записи. На странице `shkolaotcov` отдельная лекция стоит 1000 ₽, комплект из 13 — 7000 ₽. Неполный комплект не продаётся. Часть страниц Tilda на момент повторной проверки возвращала 403; для их содержимого использована сделанная ранее в тот же день выгрузка.

Отдельная запись «Любовь со стажем и романтика» (78 минут) встречается сразу на нескольких старых страницах с разными названиями. Без подтверждения соответствия она не привязана к платным карточкам. На video.ladyzenko.ru также есть «Лекция Тень» (82 минуты), но её цена не определена. DVD-фрагменты существующей библиотеки не менялись.

`lib/lecture-products.json` остаётся результатом штатной синхронизации восьми товаров Tilda. `lib/school-products.json` — отдельный каталог 12 подтверждённых записей, по 1000 ₽, доступ 30 дней. Частные URL источников не добавляются в новые файлы Git.

## Хранение и доступ

На сервере `dubai` записи импортируются в `/var/lib/new-ladyzenko-recordings` (0750 root:www-data, MP4 0640). `ops/import-recordings.py` принимает приватный JSON-манифест `{id,url,duration}[]`, скачивает MP4 до 720p, проверяет наличие видео/аудио и длительность через ffprobe. Запись получает файл `*.verified.json` только после проверки. Манифест хранится вне веб-каталога, 0600. URL и токены не выводятся в журнал.

`ops/configure-remote-media.py source|consumer` получает `{secret}` через stdin. На видеосервере `/commerce-source/` требует закрытый межсерверный заголовок; на веб-сервере `/commerce-remote/` — `internal`, проксирует только безопасные имена MP4 по HTTPS с проверкой сертификата. Приватные Nginx include имеют права 0600. Не выводить их содержимое. Резервные копии находятся в `/var/backups/new-ladyzenko-remote-media/`.

После проверки файла и доставки его имя добавляется в `lectureRemoteFiles` приватного `/var/lib/new-ladyzenko-commerce/config.json`, например `"school-lecture-02":"school-lecture-02.mp4"`. Настройка содержит только имена, не URL или секрет. Исходные восемь товаров остаются выключенными до точного сопоставления с файлами.

Покупатель оплачивает выбранную запись через ЮKassa. Подтверждённый рабочий платёж открывает видео на странице заказа и ставит письмо с личной ссылкой в очередь. Тестовый платёж, чужой заказ, истёкший срок или полный возврат не дают доступа. Браузер не получает ссылку на RuTube или межсерверный секрет. Прямые приватные URL возвращают 404. Запись экрана или уже скачанную копию отозвать невозможно.

## Проверки

`node --import tsx --test tests/*.test.ts`, `npm run build`. HTTP-тест проверяет владение заказом, неподтверждённый платёж, 30-дневный срок, возврат, тестовый режим и безопасный внутренний маршрут удалённого видео. Перед включением каждого товара требуется проверить его MP4, закрытый источник и Range-доставку через веб-сервер.
