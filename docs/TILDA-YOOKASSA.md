# Подключение ЮKassa к ladyzenko.ru на Tilda

Инструкция для человека с доступом к проекту Tilda 8102543. Основной сайт ladyzenko.ru сейчас не менялся. Реализованная здесь интеграция относится к new.ladyzenko.ru.

## Что нужно получить от владельца ЮKassa

- ShopID отдельного магазина для Tilda и секретный ключ API этого магазина. Ключ передаётся через защищённый канал и вводится только в настройках Tilda; не размещайте его в блоке HTML, коде страницы, переписке с посетителями или Git.
- Подтверждённые реквизиты и статус продавца, способ выдачи чеков и параметры налогообложения. Тариф и чеки настраивает владелец магазина.
- Утверждённые условия покупки и обработки данных; контакты по оплате и возвратам.

У new.ladyzenko.ru собственный обработчик `https://new.ladyzenko.ru/api/commerce/webhook`. Не заменяйте его обработчиком Tilda, пока новый сайт продолжает принимать платежи. Для одновременной работы сайтов используйте отдельный магазин ЮKassa для Tilda: это исключает конфликт обработчиков и настройки чеков.

## Подготовить сайт

1. Войти в аккаунт Tilda, которому принадлежит ladyzenko.ru. Открыть «Настройки сайта → Платёжные системы».
2. Создать и опубликовать страницы «Реквизиты продавца», «Условия покупки», «Политика обработки данных», «Согласие на обработку данных», добавить ссылки в подвал и корзину. На новом сайте это `/payment-info`, `/offer`, `/privacy`, `/consent`. Переносить после заполнения и подтверждения реквизитов; заменить домен и описание выдачи доступа под Tilda. ЮKassa проверяет сайт, цены, описание услуг, получение заказа и реквизиты.
3. Добавить блок корзины ST100. Поле Email сделать обязательным. Добавить два отдельных обязательных пункта: принятие условий покупки и согласие на обработку данных со ссылкой на отдельный документ. Политика доступна рядом. Рекламное согласие не включать автоматически.
4. Для консультаций создать три позиции: диагностическое интервью — 2000 ₽ / 1 час; индивидуальная консультация — 4000 ₽ / 50 минут; тестирование — 6000 ₽ / 1 час. Перед оплатой нужно согласовать встречу с Людмилой; явно написать об этом рядом с кнопкой.
5. В каталоге лекций использовать действующие цены из карточек, а не сопоставление по порядку. Идентификаторы и актуальные описания сохранены в `lib/lecture-products.json`. Продажу конкретной записи включать после подготовки доступа к ней.

## Настроить ЮKassa и Tilda

1. В ЮKassa выбрать отдельный магазин для ladyzenko.ru. В «Интеграция → Готовые решения» выбрать Tilda Publishing.
2. В Tilda выбрать «ЮKassa», тип подключения «По секретному ключу (API)», ввести ShopID и ключ нужного магазина. Валюта — RUB. Ключ тестового магазина применять только с его тестовым ShopID; боевые и тестовые реквизиты не смешивать.
3. В ЮKassa открыть «Интеграция → HTTP-уведомления». По текущей инструкции Tilda указать URL `https://forms.tildaapi.com/payment/yakassa/v3.0/` и событие `payment.succeeded`. Перед сохранением сверить значение с актуальной документацией Tilda и выбранным режимом интеграции.
4. В Tilda включить «Отправлять данные в сервисы приёма данных только после оплаты». Возврат покупателя на success-страницу не является подтверждением оплаты.
5. Настроить электронные чеки по действительному статусу продавца и выбранной схеме фискализации. Для предоплаты консультации и выдачи записи могут потребоваться разные признаки расчёта. Эти значения согласует продавец/бухгалтер; не копируйте случайные значения из примера.
6. Подключить нужные приёмщики данных к корзине и уведомления о заказах. Сохранить настройки и переопубликовать страницы с корзиной.

Если продавец работает как самозанятый на НПД, не рассчитывайте на автоматический чек ЮKassa: по текущей документации ЮKassa доход регистрируется и чек передаётся покупателю через «Мой налог» вручную. Обычная квитанция об оплате от платёжного сервиса не заменяет этот чек. В текущем запуске способ выдачи чеков отложен владельцем, поэтому рабочие платежи ещё не включены.

## Лекции: 30 дней после подтверждённой оплаты

Пока нет самих записей, продажа записей остаётся выключенной. Ниже шаги на момент, когда записи будут готовы.

1. В «Настройки сайта → Подключаемые модули → Личный кабинет» создать модуль. Создать отдельную группу/курс для каждой продаваемой лекции.
2. В группе установить срок доступа 30 дней и ожидаемый платёж, равный полной цене лекции. Связать товар с нужной группой по инструкции Tilda. У разных лекций должны быть разные группы, иначе покупка одной может открыть остальные.
3. В «Настройки сайта → Формы» подключить приёмщик «Личный кабинет» с соответствующей группой. Подключить его к корзине. Для продаж нескольких групп через каталог проверить доступность этой функции в аккаунте Tilda; по текущей документации она может требовать участия в тестировании новых функций.
4. Размещать материалы в закрытом курсе. Простая скрытая страница с общедоступной MP4-ссылкой не защищает видео: файл по такой ссылке можно смотреть без оплаты. Для размещения на video.ladyzenko.ru нужна отдельная интеграция выдачи прав; форма Tilda сама по себе эти права не создаёт.
5. Проверить письмо с данными входа, получение именно купленной лекции, отсутствие доступа к другим лекциям и автоматическое истечение доступа.

## Проверка до запуска

На отдельной непубличной тестовой странице проверить тестовым магазином: успешную оплату, отмену, повторное открытие страницы результата, задержку подтверждения, приход уведомления и письма. Не смешивать тестовые покупки и действующие платные материалы.

После одобрения рабочего магазина владелец выполняет один согласованный реальный платёж и проверяет: сумма, название магазина, банковский платёж, чек, заказ Tilda, письмо, доступ к нужному материалу. Возврат отдельно проверяется в ЮKassa и в системе доступа: нельзя предполагать, что возврат автоматически отзовёт группу Tilda. Только после проверки включить все рабочие кнопки.
